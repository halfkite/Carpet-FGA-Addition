# QuickCraft 轻松放置实体服务端支持

本扩展实现 `quickcraft:entity_place_*` 协议的服务端端点，适用于 Minecraft 1.21 和 1.21.1。客户端只提交候选 NBT，服务端重新计算实体类型、材料、距离、碰撞和权限；客户端提供的材料描述不参与校验。

## 开启

服务端默认关闭。安装扩展后使用：

```text
/carpet quickCraftEasyPlaceEntities true
```

客户端只有收到 `enabled=true` 且协议版本匹配的能力包后，才会拦截实体右键。

## 安全边界

- 会话 token 在每次 hello 后重新生成，并绑定玩家 UUID。
- nonce 只接受一次，服务端保留有限的最近 nonce；请求之间有最小间隔。
- 维度和距离按服务端玩家位置校验，reach 固定为 4.5。
- 实体类型必须存在，且必须能映射到刷怪蛋、载具物品或掉落物自身的物品堆。
- 根实体的 `UUID`、`Pos`、`Motion`、`Rotation`、`Dimension` 和 `Passengers` 不由客户端控制；乘客树首版返回 `UNSUPPORTED_ENTITY`。
- NBT 有大小上限，容器槽位按真实容量校验：漏斗矿车 5、箱子矿车 36、箱船 27。
- 材料从服务端玩家背包重新计算，等价物品会合并后再检查和扣除。
- 碰撞检查、实体创建和材料扣除失败时不会确认成功；扣料后若世界拒绝加入实体，会恢复背包快照。

## 当前支持的实体

普通生物使用对应刷怪蛋；`minecraft:item` 使用实体携带的 `Item`；盔甲架、普通矿车、箱子矿车、熔炉矿车、TNT 矿车、漏斗矿车、船和箱船使用对应物品。容器载具的 `Items` 会加入材料需求。

服务端仍然必须把客户端请求视为不可信输入。协议字段中的投影区域名和实体索引只用于调试，不是权限凭证。
