# Carpet FGA Addition 1.6.4

## 功能

- 启用 `hostileMobInventoryAccess` 后，敌对生物物品栏增加八格可持久化背包；生物死亡时会掉落背包物品

## 修复

- 修复 `removeDialogWarning` 在 Minecraft 1.21.8、1.21.10、1.21.11、26.1.2、26.2 和 26.3 的命令点击路由；已注册的服务端命令按钮可免确认执行，客户端命令保留原生处理路径
- 修复 Minecraft 1.21.9 Dedicated Server 因 End Portal / End Gateway Mixin 方法签名不匹配而无法启动的问题

## QuickCraft 兼容调整

- 移除 QuickCraft 乘客实体补放协议；常规实体轻松放置请求仍保留，依赖旧乘客实体补放 payload 的客户端不再受支持
