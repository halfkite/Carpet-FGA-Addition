# Carpet FGA Addition 1.7.0

## 新功能

- 新增 `craftableEndPortalFrame` 规则；开启后可用八个末地石围绕一个末影之眼合成末地门框架，适用于当前十个构建版本
- 新增 `silentAutoEat` 服务端规则；开启后，兼容的 halfmasa 客户端可请求服务端静默消耗背包中的食物，并保留原版营养、饱和度、效果和余留物处理
- 新增 `craftableBarrier` 规则；开启后可用八个玻璃围绕一个黑曜石合成屏障，适用于当前十个构建版本
- Minecraft 26.3 的 halfmasa 协议支持查询当前向玩家显示的凋灵和末影龙 Boss 栏血量

## 修复

- 修复切石配方开关在单人世界内置服务端未过滤配方的问题
- 修复切石规则切换后已打开的切石机仍保留旧配方、选择和产物预览的问题；关闭时按原版行为退还输入
- 修复整盒潜影盒的切石配方查询在客户端错误应用服务端规则的问题

## 兼容性

- 切石机修复和 `silentAutoEat` 覆盖当前十个构建版本：`1.21.1`、`1.21.3`、`1.21.4`、`1.21.5`、`1.21.8`、`1.21.10`、`1.21.11`、`26.1.2`、`26.2`、`26.3`
- `silentAutoEat` 默认关闭；服务端需安装 FGA、Carpet 和 Fabric API，客户端需安装对应 Minecraft 版本且支持该协议的 halfmasa 与 Fabric API，无需客户端安装 FGA
- 末地门框架与屏障合成由服务端规则控制；两项规则适用于当前十个构建版本，客户端无需安装 FGA
